# 位置、利益与局势

大多数人不是按人品行动，而是按位置行动。位置解释不了的，再考虑性格和恶意。

## 三个镜头

```
             +-- 位置：他坐在哪把椅子上？
一句话 ------+-- 成本：他说这话、做这事，代价多大？
             +-- 时间：谁急？谁拖得起？
```

### 镜头一：位置

问清楚五件事：

- 他的考核指标是什么？
- 他的上级是谁，向谁汇报？
- 他的资源从哪里来？
- 他的风险敞口在哪，最怕出什么事？
- 他可不可以被替代？

位置决定了他"必须"做什么。很多让你难受的动作，只是他在完成自己的考核。

### 镜头二：成本

信号的可信度，取决于发出信号的成本。

- **廉价信号**：口头承诺、饭桌表态、群里的热情、拍胸脯。
- **昂贵信号**：签字、公开站队、真金白银、拿自己的前途担保、写进合同。

听其言，更要观其行。一个人愿意为你付出多大成本，才是他的真实态度。

### 镜头三：时间

- 谁在拖？谁在催？
- 时间对谁有利？
- 这件事什么时候必须出结果？

很多"弯弯绕绕"不是阴谋，是拖延：拖到你急，拖到你先亮牌，拖到条件变化。

## 五事判势

出自《孙子兵法》，当作检查表用，不要当台词背。

| 五事 | 现代问题 |
| --- | --- |
| 道 | 这事在道理、规则、舆论上站得住吗？人心向谁？ |
| 天 | 时机对吗？大势往哪走？现在是不是时候？ |
| 地 | 战场在哪？谁的主场？信息在谁手里？ |
| 将 | 谁拍板？他要什么？怕什么？他的风格是什么？ |
| 法 | 制度、流程、先例怎么规定？程序上谁占优？ |

五项里如果有三项明显不利，就不要硬打。先换战场、换时机，或者干脆不打。

## 利益地图

把局里的人列出来，每人填四格：

```
姓名/角色 | 要什么 | 怕什么 | 能做什么 | 不能做什么
```

填不出来的格子，就是你需要打听或观察的地方。

常见利益货币：

- 钱、预算、资源
- 权、签字权、决策权
- 名、曝光、功劳、评价
- 时间、清闲、少干活
- 风险、责任、背锅
- 面子、关系、人情

同一个人可能同时在乎几种，但通常有一种是主导的。找到主导货币，才知道怎么和他交换。

## 量己

分析别人之前，先量自己：

- **暴露面**：我现在最容易被攻击的地方是什么？
- **筹码**：我有什么是对方需要的？
- **时间压力**：我急不急？能不能拖？
- **退路**：最坏情况下，我能走到哪里？
- **底线**：什么事我不能做，什么话我说不出口？

没有退路的人容易被迫接受坏条件。先给自己留退路，再谈策略。

## 案例：跨部门推诿

- **位置**：对方部门考核的是本部门指标，不是你的项目进度。
- **成本**：帮你做事，他要承担额外工作量和出错风险，收益却归你。
- **时间**：你不催，他就一直拖；你催得越急，他越有筹码。
- **五事**：道在你这边（项目是公司定的），地在他那边（资源在他手里），将不确定（他的领导是否支持）。
- **对策**：不要私下反复求他。把需求变成他领导的指标，或者把问题升级到共同上级，用流程解决，而不是用情绪解决。

## 纪律

- 先假设对方是理性的、被位置驱动的，再考虑个人恶意。
- 不把"他对我不好"等同于"他是坏人"。
- 利益地图是动态的。人换了位置，立场就会变。
- 看清结构，不代表要利用结构害人。看清是为了不被结构碾过去。
