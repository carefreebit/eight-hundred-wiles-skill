# 经验层：战例、规律与校准

方法可以通用，经验必须私人。这一份文档定义怎么记、怎么查、怎么提炼。

## 分层

```
方法层   skill 目录，随 skill 分发，可公开
经验层   ~/.claude/xinyanzi/，只属于用户，不发布
```

经验层永远不写进 skill 目录。升级 skill 不会覆盖个人数据，发布 skill 也不会泄露个人经历。

## 目录结构

```
~/.claude/xinyanzi/
  PROFILE.md       主公画像
  INDEX.md         一页纸索引
  cases/           战例，一事一档
    _template.md   战例模板
  patterns.md      规律：别人的套路 / 自己的坑 / 校准记录
```

模板来自 skill 的 `references/templates/`。首次使用时复制，已存在则不覆盖。

## 战例格式

每条战例包含：

- **编号**：`YYYY-MM-DD-序号`，例如 `2026-11-13-001`
- **状态**：`open` 进行中 / `closed` 已有结果
- **领域**：`workplace` / `officialdom` / `renqing`
- **标签**：用于检索，例如 `画饼`、`甩锅`、`口头授权`
- **情境**：发生了什么，谁说了什么，什么场合
- **当时信号**：事后看，其实早有迹象
- **我的动作**：当时怎么做的
- **结果**：后来怎么样了
- **教训**：下次遇到类似情况怎么办
- **事实与推断**：分开写，避免把猜测当事实

完整模板见 `references/templates/case-template.md`。

## 规律格式

规律分两栏，都放在 `patterns.md`：

### 别人的套路

```
### P-001 一句话规律
- 信号：
- 对策：
- 出现次数：1
- 情境：
- 置信度：低 / 中 / 高
- 反例：
```

### 自己的坑

```
### M-001 一句话规律
- 表现：
- 代价：
- 下次：
- 出现次数：1
```

自己的坑，往往比别人的套路更值钱。急着表态、不好意思拒绝、太想证明自己，这些模式一旦识别出来，能省很多学费。

## 查账

分析前：

1. 读 `INDEX.md`，按领域和标签找相似战例。
2. 只读命中的战例，不全量加载。
3. 命中时用一句话引用："你上次也遇到过类似的，当时是 X，结果是 Y。"
4. 没有命中就明说，不硬凑。

## 记账

触发时机：

- 用户做了真实决策
- 用户主动讲一件过去的事（补录）
- 复盘结束

规则：

1. **先问再写。** 用户同意才落盘；用户说"记一下"则直接写。
2. **先记 open。** 结果没出来，只记情境、信号、动作。
3. **去标识化。** 不写真实姓名，用角色或化名。
4. **事实与推断分开。** 推断标"我推测"。
5. **更新索引。** 加一行：编号、日期、领域、一句话、状态。
6. **索引不超过一页。** 超过就合并同类，或把旧战例归档到 `cases/archive/`。

## 回访

结果出现时：

1. 找到对应战例，把 `status` 改为 `closed`。
2. 补"结果"和"教训"。
3. 更新索引里的一句话和状态。
4. 如果结果与预期相反，走"校准"。

回访可以主动：下次聊到相关的人或事，问一句"上次那件事后来怎么样了？"

## 提炼

```
一次  只记录
两次  标为待观察，写进 patterns.md
三次  升级为规律，标注次数、情境、置信度
```

升级时保留证据编号，方便回溯。单次经历永远不写成普遍规律。

## 校准

当用户说"你判断错了"或结果与判断相反：

1. 记录当时的判断、实际结果、偏差原因。
2. 写进 `patterns.md` 的"校准记录"。
3. 降低相关规律的权重。
4. 下次遇到相似情境，主动提示："上次这类判断偏差过，注意 X。"

校准不是认错表演，是让系统变准。

## 过期

- 每条规律标 `context`（公司、行业、关系类型）和 `last_verified`。
- 换环境后，旧规律降权，先观察再套用。
- 超过一年未验证的规律，标"待复核"。
- 规律互相矛盾时，以最近的、样本多的为准。

## 隐私

- 不存真实姓名、身份证、联系方式、公司机密细节。
- 需要区分人时，用"直属领导 A""同事 B""客户 C"。
- 经验层不导出、不分享、不提交到 Git。
- 如果用户要求导出，先提醒隐私风险，再由用户确认。

## 首次初始化

当 `~/.claude/xinyanzi/` 不存在时：

1. 创建目录与 `cases/`。
2. 从 `references/templates/` 复制 `PROFILE.md`、`INDEX.md`、`patterns.md`、`case-template.md`。
3. 已存在的文件不覆盖。
4. 不主动追问个人信息；用户愿意填再填。

## 纪律

- 不记人，记事。
- 不记情绪，记信号。
- 不因一次吃亏改变对所有人的默认假设。
- 记下来是为了下次更清醒，不是为了记仇。
