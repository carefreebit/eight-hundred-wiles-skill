# 判断纪律

看破的前提，是知道自己什么时候没看破。这一份文档专门用来防止过度解读。

## 三种解读

任何一个让你不舒服的行为，至少先给出三种解释：

```
A 最平凡    忙、疏忽、层级不够、流程如此
B 利益驱动  他在完成自己的考核，或保护自己的风险
C 针对性    他确实在针对你
```

顺序很重要：先排 A，再排 B，最后才考虑 C。

> 能用愚蠢、忙碌或制度解释的，不要先用恶意解释。

## 证据分级

给每条信息标一个级别：

| 级别 | 含义 | 例子 |
| --- | --- | --- |
| 事实 | 你亲眼看到、亲耳听到、有记录 | 会议纪要把你漏了 |
| 高置信推断 | 多个信号指向同一方向 | 连续三次没通知你，且都是关键会 |
| 低置信推测 | 单一信号，或依赖他人转述 | 某同事说你"最近风评不好" |

输出时把级别写出来。**不要把低置信推测说成事实。**

## 把握度

用"几成"表达，不用"肯定"。

- **八成以上**：有直接证据，且没有明显反证。
- **五到七成**：有多个间接信号，但存在其他解释。
- **三到五成**：只有单一信号，或信息来自不可靠渠道。
- **三成以下**：基本是猜测，只能用来提醒自己观察，不能用来行动。

每个判断后面加一句：**什么信号会让我改变这个判断。**

## 反证与可证伪

一个好的判断，必须能被证伪。

- 如果他是针对我，那么他对别人应该不一样。→ 去看他对别人。
- 如果是制度导致，那么换个人也会遇到。→ 去看别人的遭遇。
- 如果是疏忽，那么提醒一次之后应该改善。→ 提醒一次，看下一次。

找不到反证，不代表判断对，只代表你还没找到。

## 低成本验证

在押上重大动作之前，先用最小成本试探。

- 发一封抄送相关人的确认邮件，看谁回复、谁沉默。
- 在公开场合问一个中性问题，看谁接、谁躲。
- 请一个信得过的人侧面打听，不直接对质。
- 提一个小的、可撤回的请求，看对方反应。

验证的成本，永远低于误判的成本。

## 防过拟合

```
一次  是意外
两次  是模式
三次  才是规律
```

- 单次经历只记录，不形成规则。
- 两次相似，标为"待观察"，仍保留其他解释。
- 三次以上，才写进规律库，并标注适用情境。

换公司、换行业、换层级之后，旧规律要降权。**环境变了，人性没变，但利益结构变了。**

## 常见偏差

| 偏差 | 表现 | 对策 |
| --- | --- | --- |
| 基本归因错误 | 别人出错是人品，自己出错是环境 | 先找处境原因 |
| 确认偏误 | 只收集支持自己判断的证据 | 主动找反证 |
| 损失厌恶 | 怕失去，所以不敢止损 | 问"如果今天重新选择，我还会选它吗" |
| 沉没成本 | 已经投入太多，不甘心退出 | 只看未来收益，不看过去投入 |
| 幸存者偏差 | 只看到成功案例 | 去看失败的人做错了什么 |
| 投射 | 用自己的想法猜别人 | 用对方的利益和位置去推 |

## 情绪与判断

愤怒、恐惧、委屈，都会让判断变形。

- 情绪强度高时，只做记录，不做结论。
- 先写下事实、你的诉求、你担心的最坏结果。
- 睡一觉，第二天再看，通常会看到不同的解释。
- 不在情绪高点发消息、签字、摊牌。

## 示例：一次没被通知

事实：一个跨部门会议，你没被拉进群。

三种解读：

- **A 疏忽**：组织者按旧名单拉的群。验证：问一句"这次会议需要我参加吗"，看对方反应。
- **B 流程**：这个会本来就不需要你这个层级。验证：看参会名单里有没有同层级的人。
- **C 隔离**：有人刻意把你排除。验证：看是否连续发生，以及会后有没有人向你同步。

低成本动作：先发一条中性消息询问，不质问、不控诉。根据回复和后续行为，再决定要不要升级判断。

## 纪律

- 先给三种解释，再下结论。
- 标级别，标把握，标反证。
- 单次不立规，两次才观察，三次才入册。
- 情绪上头时，判断暂停。
