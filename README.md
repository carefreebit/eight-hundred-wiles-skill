# 八百个心眼子

[English](README.en.md) | 中文

> 看破不点破，防人不防心。

**别人还在生气，你已经看清了局。**
**不是教你变坏，是教你别被人当傻子。**

一个给普通人的"心眼子"训练场：拆解职场、体制内、人情场里的潜台词、利益结构和制度逻辑。先给你判断和对策，再陪你把每次经历沉淀成下一次的直觉。

---

## 为什么需要它

你有没有过这些时刻：

- 领导说"你看着办"，你办了，出事却是你担。
- 公司发了一纸新规，你照做，最后发现成本全落在你头上。
- 同事在会上把你的方案说成他的，你当时没反应过来。
- 亲戚朋友开口借钱，你不好意思拒绝，钱和关系一起没了。
- 事情过去半年，你才想明白：当时那句话是这个意思。

不是你笨，是没人教过你怎么看这些。学校教知识，公司教业务，却没人教你看人、看局、看制度背后的账。

**八百个心眼子，补的就是这一课。**

## 它到底能帮你做什么

### 1. 听懂话外音

一句话，拆成三层：字面、潜台词、行为信号。谁被通知、谁被跳过、称呼变没变、为什么在这个时候说——信号比话更可信。

### 2. 看穿制度与政策的账

一份规定，先问三句：谁写的、为谁写的、成本落在谁头上。再看三层：文本怎么写、执行怎么做、真正想要什么。

### 3. 判断一个局该不该进

用"道、天、地、将、法"五事判势，再看位置、成本、时间三个镜头。该争、该缓、该走，心里有数。

### 4. 给出能落地的对策

不是空讲道理。上中下三策、拒绝三段式、买时间、留痕、边界——每一招都能直接说出口、直接做。

### 5. 把经历变成经验

每次真实事件都能记成战例：当时什么信号、你做了什么、结果如何、下次怎么办。同类事件出现两次，提炼成规律；出现三次，变成你的直觉。

### 6. 防止自己变成疑神疑鬼的人

每个判断至少给三种解释：平凡、利益驱动、针对性。证据不足时，先按最平凡的解释走。看破，不等于被害妄想。

## 它不做什么

- 不教你算计、陷害、造谣、离间、PUA
- 不做人格测评、心理诊断、命理预测
- 不替你做决定
- 不替代法律、医疗、财务等专业意见

**它只做防御：让你少吃亏、不上当、守住边界。**

## 适合谁

- 职场新人，听不懂领导的话外音
- 体制内的人，想把责任和程序看明白
- 经常处理人情往来，不想被人情绑架
- 吃过亏，想把教训变成经验的人
- 想让自己"长点心眼"的普通人

**不适合：** 想学怎么害人的人。

## 怎么用

### 第一步：描述场景

不用讲究格式，把你知道的都倒出来。至少给这几样：

| 要素 | 例子 |
| --- | --- |
| 原话 | "领导说：这个项目你牵头，出了成绩都是你的。" |
| 场合 | 私下、办公室、只有我们俩 |
| 关系 | 我的直属领导，上个月刚换的 |
| 前情 | 原来的负责人上个月离职了 |
| 担心 | 怕背锅，也怕显得不积极 |

信息不全也可以，它会先给暂定判断，再问你最关键的一两个问题。

### 第二步：看军师短报

默认输出半屏以内：

```
【判断】他在把责任往你身上挪，不是在给你机会。
【要害】授权没给、资源没给、失败兜底没提。
【你现在】可以接，但不能空手接。
【做三件事】1. ... 2. ... 3. ...
【可以说】"我愿意干，但想先跟您确认三件事。"
【把握】七成。如果他愿意白纸黑字确认，就是真培养。
```

### 第三步：按需展开

短报结尾会给你两三个具体方向，回一个字母或一句话就行：

```
要不要展开？
  A. 拆他的动机（三种可能 + 各自信号）
  B. 给软 / 中 / 硬三套话术
  C. 推演他下一步，以及你的兜底
```

也可以直接说"展开说说""再细点""给我三套话术"。

紧急或高风险的事（可能丢工作、丢钱、丢关系），它会跳过询问，直接给完整方案。

### 第四步：记账，等结果

事情有结果后，回去告诉它，它会把战例从"进行中"改成"已结束"，并提炼教训：

> "上次那个项目，后来他确实没给资源，我按你说的要了书面确认，他没回，我就只接了协调不接结果。"

它会记录：当时的信号、你的动作、实际结果、下次怎么办。

### 第五步：查旧账

以后再遇到类似的事，先问一句：

> "我以前是不是遇到过类似的？"

它会读你的个人索引，命中就说"你上次也遇到过，当时是……结果是……"，没命中就明说没有，不硬凑。

### 三种常用姿势

**解码** —— 贴一句原话，或者描述一个场景。

> "他这话什么意思？"

**定策** —— 说清你的位置、筹码和担心。

> "这个功劳我要不要争？怎么争？"

**复盘** —— 讲一件已经发生的事。

> "去年有件事我一直没想明白，帮我复盘一下。"

### 常用指令

| 你想做什么 | 这样说 |
| --- | --- |
| 拆一句话 | "他这话什么意思？" |
| 看一份文件 | "这份规定到底在管什么？" |
| 要应对方案 | "我该怎么办？" |
| 要话术 | "给我一句能直接说的" |
| 展开细节 | "展开说说" / 选 A / B / C |
| 记一笔 | "帮我记一下" |
| 查旧账 | "我以前遇到过类似的吗？" |
| 复盘旧事 | "帮我复盘一下去年那件事" |
| 归纳规律 | "把这些事归纳一下" |

### 怎么问更准

- **给原话**，不要只给转述后的意思。
- **给场合**，同一句话在会上和在饭桌上完全不同。
- **给关系**，对方能不能决定你的考核、资源、去留。
- **说担心**，你怕什么，决定它优先给你防哪一头。
- **别撒谎**，信息越真，判断越准。

### 一次完整对话长这样

> **你：** 领导今天私下跟我说"这个项目你牵头，年轻人多锻炼，出了成绩都是你的"。原来的负责人上个月离职了。我担心是坑。
>
> **它：** 【判断】他在把责任往你身上挪，不是在给你机会。……（短报）
>
> **你：** 展开 B。
>
> **它：** 软 / 中 / 硬三套接法：软——接协调不接结果；中——接但先谈授权；硬——先问清楚再答复。每套附一句原话。
>
> **你：** 我选了中，他答应了。帮我记一下。
>
> **它：** 已记录，状态：进行中。等有结果再回来补。

## 设计原则

- **方法层与经验层分离**：方法可分享，经验只属于你。
- **先结论，再备询**：像军师，先定调，再问要不要细说。
- **先平凡，后恶意**：证据不足时，先按最平凡的解释走。
- **一次意外，两次模式，三次规律**：不让单次经历变成偏见。
- **不记人，记事**：只存行为与信号，不存姓名与恩怨。
- **看破不点破**：信息优势不等于行动优势。
