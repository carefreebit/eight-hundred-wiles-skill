# 八百个心眼子

[English](README.en.md) | 中文

> 看破不点破，防人不防心。

**别人还在生气，你已经看清了局。**
**不是教你变坏，是教你别被人当傻子。**

一个给普通人的"心眼子"训练场：拆解职场、体制内、人情场里的潜台词、利益结构和制度逻辑。先给你判断和对策，再陪你把每次经历沉淀成下一次的直觉。

---

## 为什么需要它

你有没有过这些时刻：

- 领导说"你看着办"，你办了，出事却是你担。
- 公司发了一纸新规，你照做，最后发现成本全落在你头上。
- 同事在会上把你的方案说成他的，你当时没反应过来。
- 亲戚朋友开口借钱，你不好意思拒绝，钱和关系一起没了。
- 事情过去半年，你才想明白：当时那句话是这个意思。

不是你笨，是没人教过你怎么看这些。学校教知识，公司教业务，却没人教你看人、看局、看制度背后的账。

**八百个心眼子，补的就是这一课。**

## 它到底能帮你做什么

### 1. 听懂话外音

一句话，拆成三层：字面、潜台词、行为信号。谁被通知、谁被跳过、称呼变没变、为什么在这个时候说——信号比话更可信。

### 2. 看穿制度与政策的账

一份规定，先问三句：谁写的、为谁写的、成本落在谁头上。再看三层：文本怎么写、执行怎么做、真正想要什么。

### 3. 判断一个局该不该进

用"道、天、地、将、法"五事判势，再看位置、成本、时间三个镜头。该争、该缓、该走，心里有数。

### 4. 给出能落地的对策

不是空讲道理。上中下三策、拒绝三段式、买时间、留痕、边界——每一招都能直接说出口、直接做。

### 5. 把经历变成经验

每次真实事件都能记成战例：当时什么信号、你做了什么、结果如何、下次怎么办。同类事件出现两次，提炼成规律；出现三次，变成你的直觉。

### 6. 防止自己变成疑神疑鬼的人

每个判断至少给三种解释：平凡、利益驱动、针对性。证据不足时，先按最平凡的解释走。看破，不等于被害妄想。

## 它不做什么

- 不教你算计、陷害、造谣、离间、PUA
- 不做人格测评、心理诊断、命理预测
- 不替你做决定
- 不替代法律、医疗、财务等专业意见

**它只做防御：让你少吃亏、不上当、守住边界。**

## 适合谁

- 职场新人，听不懂领导的话外音
- 体制内的人，想把责任和程序看明白
- 经常处理人情往来，不想被人情绑架
- 吃过亏，想把教训变成经验的人
- 想让自己"长点心眼"的普通人

**不适合：** 想学怎么害人的人。

## 怎么用

直接问，像跟一个老江湖聊天：

- "领导说'这个项目你牵头，出了成绩都是你的'，他什么意思？"
- "公司发文要求所有对外承诺走审批，这是在管什么？"
- "同事在会上把我做的方案说成他的，我该怎么办？"
- "我以前遇到过类似的事，帮我复盘一下。"

默认给你一份**军师短报**：判断、要害、三件事、一句话术、把握度。看完说"展开"，再给完整推演。

### 三种常用姿势

**解码**

> 贴一句原话，或者描述一个场景。它告诉你台面在说什么、台下在说什么。

**定策**

> 说清你的位置和担心。它给你上中下三策，以及最坏情况怎么兜底。

**复盘**

> 讲一件过去的事。它帮你还原信号、提炼教训，记进你的个人战例库。

## 安装

把整个 `xinyanzi/` 目录放到用户级 skill 目录：

```
~/.claude/skills/xinyanzi/
```

或放到项目级：

```
<project>/.claude/skills/xinyanzi/
```

重启 Claude Code 后生效。skill 名称是 `xinyanzi`，中文名"八百个心眼子"。

## 你的经验，只属于你

方法层随 skill 走，可以分享；经验层存在你自己的电脑里：

```
~/.claude/xinyanzi/
  PROFILE.md     主公画像
  INDEX.md       一页纸索引
  cases/         战例，一事一档
  patterns.md    规律：别人的套路 / 自己的坑 / 校准记录
```

- 不记真实姓名，用角色或化名
- 不发布、不分享、不上传
- 第一次记账时自动创建

## 设计原则

- **方法层与经验层分离**：方法可分享，经验只属于你。
- **先结论，再备询**：像军师，先定调，再问要不要细说。
- **先平凡，后恶意**：证据不足时，先按最平凡的解释走。
- **一次意外，两次模式，三次规律**：不让单次经历变成偏见。
- **不记人，记事**：只存行为与信号，不存姓名与恩怨。
- **看破不点破**：信息优势不等于行动优势。

## 一句话

**心眼子不是坏词。它只是让你在别人还没反应过来的时候，先看清这个局。**
